## ✨ Features

- 🛒 **Product Showcase** - elegant furniture display with image sections
- 📱 **Fully Responsive** - mobile-first layout using Bootstrap grid system
- 🎨 **Modern Design** - clean typography, whitespace-focused layout
- 🦶 **Elegant Footer** - structured links and brand information

## 🚀 Run locally

```bash
# Clone the repo
git clone https://github.com/FrontendDevSQ/Panto-Furniture-Landing-Page.git

# Open in browser
cd Panto-Furniture-Landing-Page
open index.html
```
No installs. No build step. Just open and view.
